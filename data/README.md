# Data

## Maps

`maps/` holds occupancy grids produced by SLAM Toolbox from a teleop drive of
the Gazebo campus world:

```bash
docker compose --profile sim run --rm sim
ros2 launch shuttle_bringup slam.launch.py rviz:=true
# drive with teleop_twist_keyboard, then:
ros2 run nav2_map_server map_saver_cli -f data/maps/campus_map
```

A `.pgm` plus `.yaml` pair lands here and `nav2.launch.py` picks it up.

Maps are not committed. They are a few hundred kilobytes of binary that changes
on every remap and they are reproducible from the world file in two minutes.
The world (`simulation/worlds/campus.sdf`) is the source of truth.

## Rosbags

Bags are **not** stored in this repository, per the `.gitattributes` policy:
large binaries belong in Releases or Git LFS, not in the git history.

Record one during a comparison run with:

```bash
ros2 bag record -o data/bags/run_$(date +%s) \
    /scan /imu/data /wheel/odom /odometry/filtered \
    /ground_truth/odom /plan /cmd_vel_in /cmd_vel /tracking_error
```

`data/bags/` is gitignored.

## Datasets and licences

No external datasets are used. Every input in this repository is either
generated by the Gazebo simulation or synthesised by a script here
(`shuttle_perception/synth_calib_data.py`), so there are no third-party dataset
licences to record.
